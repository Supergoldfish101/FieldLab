## Source downloads

Both downloads accompany the browser distribution:

- [Preferred editable FieldLab source](https://fieldlab.ve6kix.com/source/fieldlab-source.zip): application, docs, tests, build/release scripts and vendored runtime. Generated by `scripts/package-source.py`; source archives themselves are excluded to avoid recursion.
- [NEC upstream corresponding source](https://fieldlab.ve6kix.com/source/necpp-wasm-v0.9.0-source.tar.gz): native C++, JS/TypeScript wrapper sources, interface definitions, CMake inputs, package lockfile, build scripts and included dependency sources/notices.

Upstream: https://github.com/andrekuehne/necpp/tree/wasm-v0.9.0.

## Building the NEC engine from source

Normal FieldLab use and its tests use the included runtime; rebuilding NEC is a separate task. Extract the NEC archive and read its `INSTALL.md`, `packages/necpp-wasm/README.md` and scripts before building. The inspected native build requires CMake 3.16 or newer and a C++17 compiler; Eigen headers are bundled. The WASM build uses Emscripten. The included Docker wrappers pin `emscripten/emsdk:4.0.7`, require Node 24 or later, install the locked wrapper build dependencies and run upstream WASM tests:

```sh
# From the extracted upstream source root, with Docker running:
./scripts/build_wasm_docker.sh
# Windows PowerShell alternative:
# .\scripts\build_wasm_docker.ps1
```

Wrapper assembly uses the package's pinned TypeScript compiler and requires both NEC and field-evaluator generated JS/WASM artifacts. The included scripts and documentation are the authoritative build recipe; do not assume that rebuilding only the native CLI regenerates the browser package.

## Redistribution and audit limits

Preserve the project license, applicable per-file/vendor notices and equivalent access to the matching editable and upstream sources when distributing the browser application or modified binaries. GPL v2 sections 2 and 3 describe modification notices, licensing and corresponding-source conditions; consult `LICENSE` for the complete terms. Do not remove the source links from a hosted derivative.

The October 2026 audit inspected license declarations, headers, archive contents, build scripts and runtime provenance. Application tests and browser checks execute the bundled NEC WASM. It did not independently rebuild the complete upstream archive or establish bit-for-bit correspondence between a fresh native build and the shipped binaries. This is a technical inventory, not a legal compliance certification or a new grant of rights beyond the existing licenses.
